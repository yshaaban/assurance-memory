# Working on Assurance Memory

Keep the assurance kernel as the only policy/evidence authority. Local analysis is an investigation projection: candidates and import reachability cannot approve requirements, establish behavior, or close debt.

Use Node 24.16+ and JDK 21. Run `npm test` after changes to shared extraction, MCP, or core behavior. `npm run test:local` is the focused SQLite/CLI suite. For storage or service changes, run the real PostgreSQL profile and restart smoke check described in README. Measure projection and parser performance separately.

Do not silently truncate scan inventories, adopt changed requirement revisions, or drop counterevidence. Preserve atomic workspace scans, read snapshot consistency, deterministic identities and explicit coverage gaps. Share local query behavior between CLI and MCP through `local-query.ts`.

New detectors must produce investigation candidates with source provenance and a falsifiable validation step. Add behavior tests for invalidation, deletion, false confidence or consistency risks; avoid tests that only mirror SQL wiring. Do not report synthetic scale measurements as production capacity or model checking as implementation proof.
